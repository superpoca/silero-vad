# Silero VAD v4 / v5 / v6、TEN-VAD 与 FireRedVAD 评估结果

数值来自 `eval_vad_results.json`（阈值 **0.5**，16 kHz）。Silero hop **512**（31.25 ms）；TEN-VAD hop **256**（16 ms），走 `D:\ten-vad\lib\Windows\x64\ten_vad.dll`；FireRed hop **160**（10 ms），走 `D:\FireRedVAD\pretrained_models\onnx_models\fireredvad_stream_vad_with_cache.onnx`（conda 环境 `fireredvad`）。协议、数据范围、打标规则见 [`eval_vad_datasets.md`](eval_vad_datasets.md)。

772 个文件、132.13 小时，微平均。主指标是 **ROC-AUC**。各模型的帧格子不同，表里并排是为了看各自原生窗上的帧级质量，不是同一毫秒网格上的逐帧对齐。`overall` **不宜当综合分**。

---

## 1. 怎么读表

每个单元格默认是 `AUC / Acc@0.5 / F1@0.5`。AUC 不依赖阈值，适合对比。Acc 与 F1 用官方默认阈值 0.5。

| 缩写 | 含义 |
| --- | --- |
| AUC | ROC-AUC，概率排序质量 |
| Acc | 正确帧 / 总帧 |
| P / R / F1 | 精确率 / 召回率 / 二者调和平均 |
| FAR | 非语音上的虚警率，FP / (FP+TN) |
| MR | 语音上的漏检率，FN / (FN+TP) |
| RTF | 推理秒 / 音频秒（Silero 为 CPU ORT；TEN 为 DLL；FireRed 为 fbank+CMVN+ORT；不含解码与解析标注） |

**结论（按条件，不按 overall）：**

- **VoxConverse**：v6 最好，v5 接近；TEN 介于 v4 与 v5 之间（全部 AUC 0.936，test 0.930）。FireRed 全部 AUC **0.923**，与 v4 持平，低于 TEN / v5 / v6；Acc/F1@0.5（0.892 / 0.938）也略低于这三家。test 上 Silero / TEN / FireRed 的 AUC 都与 [Silero Quality Metrics](https://github.com/snakers4/silero-vad/wiki/Quality-Metrics) 同量级（见第 3 节）。
- **AISHELL-5 近场**：Silero 三个版本 AUC 都在 0.90 附近；FireRed 0.896，紧随其后；TEN 明显低一截（0.863）。FireRed 在 0.5 下偏「少检」：精确率 0.918、FAR 仅 0.055，召回 0.752。Acc 0.858 与 v6（0.854）同一档，F1 0.827 接近 v4/v6。TEN 召回高（0.844）但虚警也高（FAR 0.350）。v6 的 F1 仍最高（0.832）。
- **AISHELL-5 远场**：FireRed 的 AUC（**0.849**）是五家里最高的，略高于 TEN（0.838）和 v5/v6（约 0.82）。但 0.5 工作点很保守：召回只有 0.514，Acc/F1（0.597 / 0.669）接近 v4，明显低于 TEN（0.734 / 0.807）。远场真值是会话级「有人在说」，见协议第 4.2 节。

## 6. 速度（RTF）

CPU 上按文件多进程。Silero / FireRed 每进程 1 个 ORT 线程；TEN 每文件一个 DLL handle。Silero / TEN 的 RTF 只含模型前向；FireRed 的 RTF **包含** Kaldi fbank + CMVN + ORT（没有前端就没有网络输入）。Silero / TEN 是数百倍实时；FireRed 大约 7 倍实时（10 ms 帧 + fbank）。

| 条件 | v4 RTF | v5 RTF | v6 RTF | ten RTF | firered RTF |
| --- | ---: | ---: | ---: | ---: | ---: |
| 近场全部 | 0.0072 | 0.0059 | 0.0046 | 0.0054 | 0.138 |
| 远场全部 | 0.0077 | 0.0060 | 0.0054 | 0.0059 | 0.129 |
| VoxConverse 全部 | 0.0079 | 0.0060 | 0.0061 | 0.0060 | 0.160 |
| overall | 0.0077 | 0.0060 | 0.0056 | 0.0059 | 0.146 |

FireRed 明显更慢，质量对比不依赖与 Silero/TEN 的速度对齐。
